# Attachments

Place your email attachments in this directory.

## Supported file types:
- PDF documents
- Excel spreadsheets (.xlsx, .xls)
- Word documents (.docx, .doc)
- Images (.jpg, .png, .gif)
- Any other file type

## Usage:
Files placed here will be available for attachment in your email automations.

## Tips:
- Keep file sizes reasonable (< 10MB per file)
- Use descriptive file names
- Scan files for viruses before attaching
- Consider using cloud storage links for large files
