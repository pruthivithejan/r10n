# Email Lists

This directory contains email lists for your automations.

## Format:
Create a text file with one email address per line:

```
user1@example.com
user2@example.com
user3@example.com
```

## Example files:
- Create your email lists here
- Use descriptive names (e.g., `workshop_participants.txt`, `newsletter_subscribers.txt`)
- Keep different campaigns in separate files
